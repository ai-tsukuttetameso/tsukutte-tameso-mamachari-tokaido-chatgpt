# ママチャリ東海道（ChatGPT版）

[ブラウザで遊ぶ](https://ai-tsukuttetameso.github.io/tsukutte-tameso-mamachari-tokaido-chatgpt/)

`index.html` をブラウザで開くだけで遊べる、自転車の横スクロールゲームです。インストールやビルドは不要です。HTML・CSS・JavaScript・Canvasの絵・効果音をすべてこの1ファイルに収めています。画像、外部フォント、外部ライブラリ、通信は使用しません。

## 操作

- 出発画面で「やさしい／ふつう／むずかしい」を選びます。
- クリック・タップ・スペースキー・↑キーでジャンプ。着地まで2回まで跳べます。
- 下の「ジャンプ」ボタンでも操作できます。
- P／Escまたは「停止」で一時停止。別タブに移動しても自動停止します。
- 「音 切」を押すとピコピコ効果音が鳴ります。Mキーでも切り替えられます。
- 結果画面の「もう一度走る」で即リトライできます。

## ゲームの内容

- 自動走行と速度上昇。平地・上り坂・下り坂・谷・壁が続きます。
- 谷に落ちるか、壁の正面にぶつかるとゲームオーバー。
- 崖と壁の手前にある黄色い印の付近で踏み切ると1〜3回転。印の右端に近づくほど回転数が増えます。壁の印は高さ・速度に応じて、ジャンプで越えられる位置に置かれます。
- 回転を伴うジャンプを着地まで決めるとコンボ。通常ジャンプの着地で途切れます。
- 難易度ごとに固定コース。最長記録のジャンプ操作を半透明のゴーストとして再生します。
- 難易度別のベスト・ゴーストは同じブラウザの保存領域に記録します。保存が利用できない場合も、その画面を開いている間は記録を保持します。
- 朝→昼→夕→夜を約100秒で一巡。夜はライトの範囲を中心に道が見えます。

## 東海道の旅

名古屋 → 岡崎 → 浜名湖 → 静岡 → 富士 → 箱根 → 横浜 → 東京。

名古屋城、浜名湖の湖面、茶畑、富士山、箱根の温泉、港、東京の街をCanvasで描いています。地名・距離はゲーム用の目安です。走行12 mを旅の1 kmに換算し、東京の先もエンドレスで走れます。

## GitHub Pages向けの配置

公開用に必要なファイルは **index.htmlだけ** です。ファイル名をそのままにして、GitHub Pagesで配信するフォルダに置ける構成です。このリポジトリでは `main` ブランチのルートからGitHub Pagesに配信します。

保存記録はURLやブラウザごとに分かれるため、ローカルファイルと公開後のURLの記録は共有されません。
